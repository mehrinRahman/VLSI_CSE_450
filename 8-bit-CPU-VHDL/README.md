# 8-bit CPU Design Using VHDL

This project implements an 8-bit CPU using VHDL in Xilinx ISE.

## Modules
- Program Counter
- Program ROM
- ALU (Arithmetic Logic Unit)
- Control Unit
- Accumulator
- CPU Top Module
- CPU Testbench

## Tools
- VHDL
- Xilinx ISE

## Simulation
The CPU testbench is used to verify the instruction execution and accumulator output.
